Разбор кода по файлам

tsconfig.jsonПочему настройки строгие

strict включает основные проверки, а noUncheckedIndexedAccess заставляет учитывать undefined при чтении массива или объекта по key. noEmit оставляет сборку Vite, а TypeScript используется как отдельный анализатор.

shared/types/recipe.tsКак собрана доменная модель

RecipeBase хранит общие поля. RecipeDetails расширяет его. FavoriteRecipe создаётся через Pick, а search result через Omit, поэтому структура не дублируется.

type FavoriteRecipe = Pick<RecipeDetails, 'id' | 'title' | 'thumb'>
apiGuards.ts + recipesApi.tsКак unknown становится RecipeDetails

isRecord подтверждает объект, requireString проверяет обязательное поле, nullableString — optional поле. Только parser возвращает доменный type.

const response = await httpClient.get<unknown>('/lookup.php', config)
return toRecipeDetails(response.data)
favoritesApi.tsКак избранное работает на GitHub Pages

Локально при наличии VITE_FAVORITES_URL используется Express через Axios. На статическом Pages backend недоступен, поэтому тот же API layer переключается на localStorage. Компоненты и RTK Query mutations остаются без изменений.

app/api.tsЧто делает toResult и generics endpoint

toResult<T> сохраняет тип Promise и преобразует exception в форму RTK Query. builder.query<RecipeDetails | null, string> связывает argument hook и тип data.

type QueryResult<T> = { data: T } | { error: ApiError }
store.ts + hooks.tsПочему RootState не пишется вручную

ReturnType<typeof store.getState> всегда соответствует реальному reducer map. Typed hooks переносят этот тип во все компоненты без повторения generics.

shared/ui/*.tsxКак типизированы UI primitives

Button расширяет native button attributes; Input заменяет DOM onChange callback на строковый; Icon принимает только union IconName; EmptyState использует ReactNode для children.

RecipePage.tsxПочему использован skipToken

useParams() возвращает string | undefined. Non-null assertion только скрыл бы риск, а id ?? skipToken реально не запускает query без id.

FavoritesPage.tsxЗачем discriminated union и never

Одно поле status задаёт loading/error/empty/ready. У каждого состояния доступны только его данные, а never проверяет полный switch при добавлении нового status.

main.tsx + router.tsx + App.tsxЧто осталось неизменным

Provider, RouterProvider, маршруты и layout сохранились. Миграция изменила контракты и проверяемость, но не пользовательские сценарии.

Четыре приёма в React

skipToken

id ?? skipToken не отправляет запрос, если route param отсутствует.

Native props

Button расширяет ButtonHTMLAttributes, поэтому aria и events не перечисляются вручную.

Discriminated union

loading, error, empty и ready нельзя случайно смешать в противоречивое состояние.

never

Exhaustive switch станет compile-time ошибкой, если забыть новый status.

Проверь себя перед защитой

Почему API начинается с unknown?

TypeScript исчезает в runtime, а generic Axios не проверяет JSON. Нужны guards и parser.

Почему Vite build не заменяет tsc?

Vite преобразует TypeScript, но не обязан проводить полный typecheck. Нужен отдельный tsc --noEmit.

Зачем RootState выводится через ReturnType?

Так тип соответствует реальному store и не расходится с reducer map.

Что даёт noUncheckedIndexedAccess?

Элемент по индексу считается потенциально отсутствующим.

Зачем aliases есть и в tsconfig, и в Vite?

Первый нужен компилятору, второй — bundler.
